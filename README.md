# Сайт-поздравление с днём рождения

Чистые HTML, CSS и JavaScript: без сборки, npm и CDN. Весь контент лежит в `content.js`.

## Структура

```
/
├── index.html
├── style.css
├── script.js
├── content.js        ← редактируй только его
└── assets/
    ├── images/       ← фото
    ├── videos/       ← видео (лучше .mp4)
    ├── gifs/         ← гифки
    └── audio/        ← музыка (папку создай сам, если нужна)
```

Папки `assets/...` создай сам и положи в них файлы. Пути в `content.js` пиши относительные: `assets/images/photo1.jpg` (без `/` в начале).

## Как менять контент

1. Открой `content.js`.
2. Замени имя (`friendName`), заголовок, подзаголовок и подпись в `finalMessage`.
3. Чтобы добавить блок, скопируй любой объект в массиве `sections`, вставь ниже и поменяй текст или путь к файлу.
4. Типы блоков: `text`, `image`, `video`, `gif`, `gallery`.
5. Абзацы в тексте разделяй `\n\n`.
6. Музыка: положи файл в `assets/audio/` и укажи путь в `music`. В углу появится кнопка вкл/выкл. Браузеры не дают играть звуку без клика, поэтому музыка включается только по нажатию.
7. Конфетти выключается строкой `confetti: false`.

## Как выложить на GitHub Pages

1. Создай репозиторий на GitHub (например `birthday`).
2. Загрузи в корень репозитория все файлы и папку `assets` (кнопка **Add file → Upload files** или через `git push`).
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажми **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://ТВОЙ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`.

Чтобы обновить сайт, залей изменённые файлы в репозиторий. Обновление занимает около минуты.

## Локальный просмотр

Открой `index.html` двойным кликом. Если видео или шрифты ведут себя странно, запусти в папке `python3 -m http.server` и открой `http://localhost:8000`.

## Частые проблемы

- **Картинка не грузится:** проверь регистр букв и расширение. GitHub Pages различает `Photo.JPG` и `photo.jpg`.
- **Видео не играет:** сохрани его как `.mp4` в кодеке H.264. Размер файла в репозитории не должен превышать 100 МБ.
- **Старая версия сайта:** обнови страницу с очисткой кэша (Ctrl+F5).
